宏观经济学学习大纲

课程大纲 · 8 节课

L1 · 谁在参与宏观经济学这场游戏？

学习目标

  1. 理解宏观经济学的定义，并能识别宏观经济学涉及的情境。
  2. 理解政府是宏观经济学中最常见的经济主体，政府可以在地方、国家和国际层面发挥作用，并能举出地方、国家和国际经济组织的例子。

核心概念

宏观经济学研究整个经济体，例如一个国家的劳动力数量和国内生产总值（GDP）。

层级说明例子
地方负责在地区范围内提供政府服务，通常接受中央政府的资金支持。停车罚款、地区公共服务
国家中央政府，通过组合政策来实现宏观经济目标。—
国际主要存在于保护成员利益、促进自由贸易。世界贸易组织（WTO）、欧盟（EU）

活动

在设计好的情境中，学生分别扮演地方、国家和国际经济组织。

L2 · 宏观经济学这场游戏的规则是什么？

学习目标

  1. 了解五个宏观经济目标。
  2. 了解总需求（GDP）的公式。
  3. 解释五个目标的重要性：目标实现或没有实现时会发生什么。
  4. 理解五个目标之间可能互相冲突，政府必须决定采用怎样的政策组合。

五个宏观经济目标

  • 经济增长
  • 低失业率
  • 低且稳定的通货膨胀率
  • 国际收支平衡（经常账户）
  • 收入再分配

总需求公式

AD（GDP）= C + I + G +（X - M）

C = 消费 · I = 投资 · G = 政府支出 · X = 出口 · M = 进口

目标的重要性

政府希望实现经济增长，因为生产更多商品和服务可以提高人们的生活水平，例如改善营养、医疗和住房。经济增长还可能帮助实现其他目标，例如产出增加时，失业率往往会下降。

宏观经济目标之间的冲突

冲突逻辑链
经济增长与通货膨胀经济增长较快时，失业率较低 → 剩余资源的价格上升 → 生产成本上升 → 通货膨胀。
低失业率与国际收支失业率较低时，收入通常较高 → 人们能够购买更多进口商品 → 经常账户恶化。同时收入增加会提高企业生产成本 → 产品价格上涨 → 国际竞争力下降 → 出口减少。

教学提示：其他目标之间的冲突也应采用同样的方式呈现，用逻辑链解释两个目标为什么会冲突。

活动 · 利益相关者辩论

将学生分成六组，分别代表失业者、退休人员、出口企业、刚毕业的学生、非政府组织（NGO）和政府。前五组分别支持一个经济目标，向政府组解释为什么应该优先实现自己的目标。五组进行五分钟交叉辩论，政府组听取意见后选择两个优先目标，并向全班解释理由。

L3 · 怎样把这场游戏玩好 I：财政政策

学习目标

  1. 了解财政政策的定义。
  2. 理解税收是大多数国家政府收入的主要来源。
  3. 了解税收的分类（累进税、比例税和累退税），并简要分析每种税收对公民和政府的影响。

关键定义

财政政策是政府通过支出和税收影响总需求的政策。

教学提示：学生只需要理解税收作为政府收入来源的重要性，不需要展开过多细节。

税收分类

类型定义
累进税富人需要为收入或财富支付更高的税率。
比例税所有纳税人按照相同比例的收入缴税。
累退税穷人需要为收入或财富支付更高的税率。

活动

  1. 将学生分成三组，每组为一种税收类型进行辩护。
  2. 讨论税收是否公平（功利主义与自由主义的观点）。

L4 · 怎样把这场游戏玩好 II：财政政策的实际应用

学习目标

  1. 了解财政政策可以分为扩张性财政政策和紧缩性财政政策。
  2. 了解两种政策的措施，并解释这些措施如何帮助政府实现宏观经济目标。

扩张性财政政策与紧缩性财政政策

扩张性财政政策紧缩性财政政策
措施增加政府支出；减少税收。减少政府支出；增加税收。
对 GDP 的影响降低个人所得税和企业税 → 消费与投资增加 → GDP 上升；政府支出增加也会直接提高 GDP。降低工作、创业和消费的激励 → GDP 下降。
对就业的影响政府可以提供就业机会，例如修建道路 → 就业率提高。—
目的促进经济增长；减少失业。稳定价格水平；减少预算赤字；偿还政府债务。
潜在问题可能导致通货膨胀（AD > AS）；形成预算赤字。—

活动

给学生一个复杂、接近现实的情境，让他们讨论并在海报上共同制定一套完整的财政政策措施。如果时间允许，可以继续学习下一课的内容。

L5 · 怎样把这场游戏玩好 III：供给侧政策

学习目标

  1. 理解供给与需求的关系，能够绘制并分析简单的供需图（仅涉及供给或需求移动，以及移动造成的价格变化）。
  2. 了解生产可能性曲线（PPC）的定义，并理解 PPC 如何表示经济增长。
  3. 了解供给侧政策的定义。
  4. 了解供给侧政策的常见措施及其影响。
  5. 使用供需图和 PPC 图解释供给侧政策如何帮助政府实现目标。

关键定义

生产可能性曲线（PPC）表示在现有资源和技术条件下，两种产品的最大产量以及这两种产品所有可能的产量组合。

PPC 向右移动表示经济增长。

供给侧政策是旨在增加总供给的措施。总供给可以用 PPC 图表示。

教学提示：补充微观经济学中的供需内容，可参考微观经济学大纲第 4 课。除了以下内容，其他供给侧措施可以提及，但不是必需的；如果讲解，应使用逻辑链说明政策影响。

供给侧政策的常见措施

措施影响及逻辑链
改善教育与培训技能提高 → 生产率提高 → 单位生产成本降低 → 产品质量提高 → 企业销售更多并扩大规模。技能提高还会增加职业流动性，使劳动力供给更快适应需求。职业流动性指劳动者改变职业的能力。
降低税收工作和投资的激励增加 → 同样的努力能够获得更高回报。
放松管制减少进入市场的障碍 → 合规成本降低 → 更多企业进入 → 竞争加剧 → 企业提高效率 → 成本和价格下降 → 产品在国际市场上更有竞争力。
劳动力市场改革降低工会的影响力 → 生产受到的干扰减少。工会存在的目的，是保护劳动者利益；常见行动包括罢工。

PPC 与供给侧政策的关键逻辑

PPC 向右移动 → 表示经济增长 → 总供给增加。在总需求不变、总供给增加时，不会出现严重的通货膨胀。

这个层次的解释已经足够学生理解。

活动

填写一份表格。前十名完成的学生可以获得小零食。

L6 · 怎样把这场游戏玩好 IV：货币政策与汇率

学习目标

  1. 了解外汇汇率的定义（仅限浮动汇率制度）。
  2. 使用某种货币的需求与供给图，判断外汇市场中的汇率。
  3. 了解货币政策的定义。
  4. 了解货币政策可以分为扩张性和紧缩性政策，以及每种政策如何改变利率、货币供应量和汇率。
  5. 解释货币政策措施的影响。

关键定义

外汇汇率是一种货币相对于另一种货币的价格。

货币政策是政府针对货币供应量、利率和汇率作出的决策，用来影响总需求。

汇率的决定

  • 供给增加 → 汇率下降（假设需求不变），反之亦然。
  • 需求增加 → 汇率上升（假设供给不变），反之亦然。

扩张性货币政策与紧缩性货币政策

扩张性货币政策紧缩性货币政策
利率下降上升
货币供应量增加减少
汇率下降上升

扩张性货币政策的影响

变化影响及逻辑链
利率下降借款成本下降 → 消费和投资增加。
货币供应量增加经济中的流通货币增加 → 消费和投资增加。
汇率下降出口商品价格更低；进口商品价格更高。

紧缩性货币政策的影响与上面相反。

活动 · 快问快答竞赛

举办个人快问快答竞赛，复习财政政策、供给侧政策和货币政策。每道题最先答对的学生可以获得一份小零食。

L7 · 为什么要玩这场游戏：它对人们有什么影响？I - 生活水平

开场讨论

讨论（1.5 分钟）：大多数人努力工作或学习最根本的动力是什么？政府为什么要做它们正在做的事情？例如，中国共产党指出“人民对美好生活的向往，就是我们的奋斗目标”。这场讨论将引出生活水平这一主题。

学习目标

  1. 了解人类发展指数（HDI）和人均实际 GDP 是衡量生活水平的两种方式。
  2. 了解 HDI 和人均实际 GDP 的组成，并解释为什么经济发达国家的人们更可能拥有较高的生活水平。
  3. 比较人均实际 GDP 和 HDI 的优点与缺点。

组成部分

指标组成
人均实际 GDP实际 GDP ÷ 人口
HDI收入（人均国民总收入） · 健康（预期寿命） · 教育（受教育年限）

经济发达国家更可能拥有较高的 GDP、GNI，以及更好的医疗和教育资源，例如更多学校或更长的义务教育年限。

教学提示：学生只需要知道这两个指标存在，不需要在此阶段进行过多展开。

人均实际 GDP 与 HDI 的比较

人均实际 GDPHDI
优点数据容易获得；可以用于国际比较。衡量生活水平的范围更广；由联合国编制，数据客观、可信。
缺点忽略许多影响生活水平的因素；没有考虑生产的商品类型，例如 GDP 可能因为生产了许多药物或香烟而很高，但这些有害商品并不会提高生活水平。仍然没有涵盖所有因素，例如污染程度；三个维度的权重未必准确反映它们对整体生活水平的实际贡献。

活动 · 数据比较与讨论

第一部分：提供两个真实国家的数据，一个国家的人均 GDP 较高但 HDI 相对较低，另一个国家的人均 GDP 较低但 HDI 不低于前者。让学生讨论为什么会出现这种情况，并引导学生理解：收入分配不均时，高人均 GDP 不一定带来高 HDI。

第二部分：再提供两个国家的数据，其中一个国家的受教育年限、收入和预期寿命都高于另一个国家，用来复习 HDI 的组成。

L8 · 为什么要玩这场游戏：它对人们有什么影响？II - 贫困

学习目标

  1. 了解绝对贫困和相对贫困的定义。
  2. 理解贫困的原因（仅限失业、低工资、疾病和年龄）。
  3. 了解缓解贫困的政策，并解释每项政策如何发挥作用。

绝对贫困与相对贫困

类型定义
绝对贫困人们的收入不足以满足食物、干净的水和住所等最基本的需要。
相对贫困人们的收入低于经济中其他人通常用来购买商品和服务的收入水平。

贫困的原因

  • 失业：没有稳定的收入来源。
  • 低工资：需求低、劳动力供给高的工作（例如进入门槛较低的工作）通常只能提供较低工资。
  • 疾病：无法工作，同时还要承担医疗费用。
  • 年龄：老年人和非常年轻的人可能缺乏获得收入的能力。

教学提示：讲解低工资时，可以连接微观经济学中的供需图。虽然低工资还有其他原因，但学生只需要了解：通常需求低、劳动力供给高的工作，也就是进入门槛较低的工作，工资会较低。

缓解贫困的政策

政策如何缓解贫困
促进经济增长总需求增加 → 产出增加 → 创造就业机会。失业是贫困的重要原因。
改善教育增加就业机会和收入潜力，使人们能够获得因高资格或高技能要求而劳动力供给有限的工作。
国家福利为老年人、病人和残障人士提供福利，使他们能够避免陷入绝对贫困。
国家最低工资确保所有劳动者都能满足基本需要，缓解由低工资造成的低生活水平。
累进税向富人征收的税款可以用于国家福利或其他社会支出，例如补贴食物、医疗和教育，使贫困人口获得原本收入无法负担的资源。

活动 · 选项 A：中国案例研究

头脑风暴：中国采取了哪些政策来实现绝对贫困清零（全面脱贫），并减少相对贫困？准备几张供学生参考的事实卡片，制作一张海报。

活动 · 选项 B：情境小组合作

把学生分成小组，为每组提供一个不同的情境，让他们决定可以采用哪些政策来减少或消除贫困。
