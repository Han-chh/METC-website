# METC 项目背景与范围

## METC 是什么

METC（Maths and Engineering Teaching Club）是一个由高中生运营的公益教育与支教社团，长期关注数学、物理、工程、经济、实验活动和学生作品。公开网站的目标是把课程设计、课堂成果、活动照片、学生声音与社团理念以可持续维护的方式展示出来。

## 当前产品范围

已交付的公开页面：

- 首页：品牌介绍、活动入口、课程入口、学生反馈入口与社团内容。
- 课程设计：课程书架、双语课程资料、清理后的 Word 大纲和图片化课件。
- 活动成果展览：按学校组织的真实照片相册、照片墙与灯箱。
- 听 ta 们说：学生反馈的互动浏览页；现在仍是演示图，等待授权的真实内容。

当前不包含 CMS、数据库、管理后台、登录、用户系统、文件上传接口、服务器端内容审核或在线编辑功能。内容通过 Git 版本控制、配置文件和资源处理脚本维护。

## 已确认的设计方向

网站将自己定位为“教育成果展览空间”，而不是普通社团介绍页或卡通培训机构。品牌首屏围绕可见笔书写 METC、动态颜色和流动形态；中下部保留课程、活动档案、作品、便利贴式反馈、黑板和情绪化收尾等真实教育语汇。

已否决的方向：以幻想学校建筑或简笔画校园作为首页 Hero 主体。具体视觉约束见 [设计语言](DESIGN_LANGUAGE.md) 和 [首页愿景](HOMEPAGE_VISION.md)。
