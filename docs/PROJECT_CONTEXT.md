# METC Project Context

## What METC Is

METC 暂定全称为 `Maths and Engineering Teaching Club`。

它是一个由高中生运营的公益教育与支教社团，长期关注：

- 公益支教
- 数学课程
- 物理课程
- 工程制作
- 经济学课程
- 实验活动
- 学生手工作品
- 学生模型
- 课堂互动
- 在线教学
- 志愿者课程设计

## Why The Website Exists

公开网站的长期目标不是做成一个普通社团介绍页，而是把 METC 的教学成果、课堂痕迹、学生作品和社团精神可视化地展示出来。

网站未来需要承载的内容包括：

- 社团活动成果
- 活动照片
- 课程大纲
- 教学 PPT
- 学生手工实验
- 学生模型
- 学生作品
- 学生反馈
- 教师反馈
- 志愿者反思
- 合作学校
- 社团成员
- METC 教育理念
- 社团灵魂
- 不同年份的活动档案

## Current Development Scope

当前只关注公开网站前端。

当前不开发：

- CMS
- 数据库
- 管理后台
- 用户系统
- 登录系统

## Current Prototype Status

当前仓库是一个静态首页原型，技术上为：

- `index.html`
- `styles.css`
- `script.js`

原型目标是验证视觉叙事和信息入口，不是正式工程化前端。

## What Was Learned From The Prototype

原型已经验证出一些有效资产：

- 校园物件可以作为内容入口
- “作品墙 / 档案 / 便利贴 / 黑板 / 黄昏收尾”适合 METC 的教育气质
- 双语切换和滚动叙事是合理需求

原型也暴露出一个已经明确被否决的方向：

- 不应继续把“幻想学校建筑”作为首页首屏主体

## Phase 0 Outcome

Phase 0 的目标不是重写首页，而是建立统一认知：

- 明确 METC 的网站使命
- 明确旧设计与新设计的边界
- 明确哪些视觉概念继续保留
- 明确正式前端迁移路径
